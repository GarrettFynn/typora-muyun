# MuYun 慕云 · Typora Edition 开发文档

> 主题的技术架构、质量体系、发布流程与维护指南。时间线与踩坑细节见 [开发日志.md](开发日志.md)；令牌色值全表见 [PALETTE.md](../PALETTE.md)。

---

## 一、项目概览

- **定位**：[obsidian-muyun](https://github.com/GarrettFynn/obsidian-muyun) 的 Typora 姊妹版——共享同一套设计令牌（11 色池降饱和调色板、≈10:1 对比舒适带、≤200ms 动效纪律、纸感双底色）。
- **形态**：纯 CSS、零脚本、零外部字体、零构建。四个主题文件 + 门禁脚本 + 文档。
- **支持版本**：Typora 1.14.x 实测；父链高亮的 `:has()` 需 Chromium 105+（Typora 1.7+，旧版 `@supports` 守卫静默降级）。
- **双远端模型**：公开仓库（去敏，main 分支）+ 私有全量镜像（完整署名，private-full 分支 = main + 署名提交，每次发布 merge 垫顶）。

## 二、文件结构与架构

```
typora-muyun/
├── muyun.css              # 浅色·晨光暖纸 —— 全部组件规则与浅色令牌（唯一事实源）
├── muyun-dark.css         # 深色·墨蓝夜空 —— @import muyun.css + 深色令牌覆盖 + 打印块重申
├── muyun-wide.css         # 宽幅变体：@import muyun.css + --muyun-measure: 46rem
├── muyun-wide-dark.css    # 宽幅深色：@import muyun-dark.css（两级链）+ 46rem
├── demo.md                # 全格式演示文档（设计说明 + Markdown 全元素演练）
├── scripts/check-theme.mjs# 结构门禁（零依赖；--report 出对比度审计表）
├── .github/workflows/     # ci.yml（推送跑门禁）+ release.yml（tag 自动挂资产）
├── preview/               # 浏览器结构模拟页（无 Typora 环境的预览/回归）
├── screenshots/           # 实机截图（light/dark）
├── PALETTE.md / CHANGELOG.md / docs/
└── gh-pages 分支           # 在线预览站（落地页 + 扁平化预览页 + css 副本）
```

**@import 链**：`wide-dark → dark → muyun.css`。链上每一层只做增量，组件规则永远只存在于 `muyun.css` 一处。

**双态原理**：深色文件的所有规则都是「`:root` 令牌覆盖 + 深色专属修正（如 mermaid 夜间配色 `@import`、图表错误色）」。组件规则消费 `var(--muyun-*)`，令牌动态解析，深浅自动切换。

**打印层叠（关键）**：`@import` 的内容在层叠序上**先于**本文件规则。深色令牌若不重申打印覆盖，会赢过导入进来的 `@media print` 块、导出暗底 PDF——因此 **muyun-dark.css 末尾必须保留与 muyun.css 相同的打印令牌块**（门禁第 4 道自动核对此一致性）。

## 三、设计令牌体系

三层结构（定义于 `:root`，见 PALETTE.md 全表）：

1. **Typora 内建变量**（`--bg-color` / `--text-color` / `--side-bar-bg-color` / `--control-text-color` / `--select-text-bg-color` / `--active-file-*` / `--monospace` 等）——直接驱动窗口、侧栏、导出等应用铬件；
2. **`--muyun-*` 私有令牌**——纸面 / 锚点色 / 派生面 / 语法高亮 / 提示块 / 动效 / 版式，全部组件规则只消费这层；
3. **模式无关令牌**（`--muyun-measure` / `--muyun-p-spacing` / `--muyun-d1` / `--muyun-ease` / `--monospace`）——深色合法继承，不重定义。

**令牌治理（门禁自动执行的设计意图）**：

- 浅色 `:root` 中**值为颜色**（hex/rgba 启发式）的令牌，深色 `:root` 必须重定义——防止「加新颜色令牌忘了深色」的静默劣化；
- 确属双态同值的，显式登记进脚本的 `INHERITED_BY_DARK` 白名单（现为 GFM 提示块色相 5 项）——新增时强制做一次有意识的决定；
- 深浅两文件的 `@media print` 块颜色令牌集必须一致。

**代码语法（v0.3.3 全令牌接管）**：Typora 内置 codemirror.css 以同特异性硬编码浅色系（变量/键名纯黑、运算符暗红），主题逐一接管全部令牌类并给代码容器显式设基础码色兜底。语义归族：关键字慕云紫 / 字符串苔绿 / 数字陶土 / 定义墨紫 / 注释灰 / 键名链接蓝族 / 类型沙金族 / 结构符（运算符·括号）退后取灰 / 错误暗红族；未识别令牌回落正文色。

**可选开关体系**（Typora 无 Style Settings 的替代）：`muyun.css` 末尾「锦上添花批」注释块——S1 斑马纹 / S2 图片卡片 / S4 自动编号（+S4b 扩展）；`:root` 旁对比度三档注释预设（深色文件有配套档）。去掉注释即启用，重新包上即关闭。

## 四、质量体系

### 4.1 结构门禁（`scripts/check-theme.mjs`，CI 每次推送执行）

| # | 检查 | 拦截的劣化 |
| --- | --- | --- |
| ① | 文件齐全 | 误删主题文件 |
| ② | 花括号平衡（剥离注释后计数） | 手改失配（注释里的完整规则不误报） |
| ③ | `@import` 链可解析 + 变体可达 muyun.css | 引用断链；`night/` 前缀识别为内置跳过 |
| ④ | 令牌完备性（三向：深色覆盖 / 打印块一致 / `var()` 可解析） | 深色漏配新颜色令牌；暗底 PDF；拼写错 |
| ⑤ | WCAG 对比度门禁（正文 ≥9:1，余项 ≥4.5:1） | 换色后可读性劣化 |

六种人为破坏已验证逐一拦截。改令牌后跑 `--report` 刷新 PALETTE 审计表。

### 4.2 四层验证

1. **门禁**（结构层，秒级）；
2. **浏览器模拟渲染**（`preview/` 双态页，本地 `python -m http.server` + 截图/计算样式断言）——快速回归配色与版式；
3. **打印态模拟**（把 `@media print` 转 `@media all` 注入，层叠与真实打印一致）——断言白底、打印色、防孤行、表头组；
4. **真机验证**（Win32 窗口捕获）。

**真机截图法**（CDP 被 Typora 反调试拦截后的替代方案）：十六进制 profile.data 临时切主题 → 启动 Typora 打开测试文档 → PowerShell `SetProcessDPIAware` + `ShowWindow` + `MoveWindow` 定尺 + `SetForegroundWindow` → `DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)` 取可见帧边界（勿用 `GetWindowRect`，含 DWM 阴影边距）→ `CopyFromScreen` → 截图交视觉模型逐项核对 → 关闭进程并**还原 profile 备份**（保持用户当前主题选择）。

**两条铁律**：mock 通过 ≠ 真机正确（kbd 白块、大纲错位两例皆为 mock 布局遮蔽）；断言动效元素必须等过渡结束再采样（120ms 颜色过渡的同帧采样会读到旧值）。

## 五、发布流程 SOP

```
1. 编辑源（工作副本）→ 跑门禁：node scripts/check-theme.mjs
2. 三处同步 css：仓库 / 本机 %APPDATA%\Typora\themes\ /（如涉及）编辑源副本
3. 升版本头（两个 css 首行注释）+ CHANGELOG 补段
4. commit → 需发版则打 tag vN.N.N → push 公开端 main + tag
   （Release workflow 自动触发并挂资产：4 css + demo.md + README.md）
   ※ 新仓库首次推 tag 可能漏触发：查 Actions 零运行则删 tag 重推
5. private-full 合并（署名层保持最上）→ push 私有端 private-full:main
6. gh-pages 分支同步 css 副本 → push（在线预览样式不落旧版）
7. 线上核验：API 查 CI/Release 结论；curl Pages css 文件头验版本
```

## 六、维护指南

**新增颜色令牌**：muyun.css `:root` 定义 → muyun-dark.css `:root` 配深色值（或登记 `INHERITED_BY_DARK`）→ 组件规则消费 → 门禁自动核覆盖 → `--report` 刷新审计表。

**新增可选开关**：在「锦上添花批」加完整注释块（含一句「为什么默认关」）；涉及打印态的注明豁免路径。

**新增界面组件样式**：选择器优先从 Typora 安装目录 `resources/style/*.css` 找官方既有类名（`base.css` 界面布局 / `codemirror.css` 代码令牌 / `window.css` 窗口铬件），不猜 DOM；真机截图验证。

**更新在线预览**：preview/ 改动 → gh-pages 分支同步（注意预览页 css 路径为根相对）。

**已知不做**（Typora 能力边界，写进 README 已知差异段）：Callout 全集折叠、代码块行号、内联标题、transclusion、图谱配色、图形化开关面板、配套插件的 JS 能增强项。

## 七、决策记录（ADR 摘要）

| # | 决策 | 理由 |
| --- | --- | --- |
| 1 | 深色 `@import` 复用组件规则，只覆盖令牌 | 单一事实源，两态永不漂移；后续增强写一处全态生效 |
| 2 | 组件规则只消费 `--muyun-*` 私有令牌 | 与 Typora 内建变量解耦，调色不动结构 |
| 3 | 深色文件末尾重申打印块 | @import 层叠序：不重申则深色令牌赢过打印覆盖，导出暗底 PDF |
| 4 | 注释块 = 可选开关 | Typora 无 Style Settings；默认关 + 一行启用最接近原体验 |
| 5 | 颜色值启发式 + 白名单治理令牌继承 | 门禁可执行的「设计意图显式化」；防深色漏配的静默劣化 |
| 6 | 花括号计数前剥离注释 | 注释开关块含完整规则，不剥离必误报 |
| 7 | 圆点 → 14×4 色条；挂点 `.outline-label` | Typora 大纲为 table-cell 布局；色条呼应 H2 路标条并提升色面积辨识 |
| 8 | 导航 H2 提亮独立令牌，正文 H2 双态同值不动 | 忠于原设计 vs 可读性各得其所：色值令牌分离，互不牵连 |
| 9 | 代码全令牌接管 + 基础码色兜底 | 内置硬编码与主题同特异性必然泄漏；兜底让任何未来泄漏回落正文色 |
| 10 | 真机 Win32 截图而非 CDP | Typora 带调试参启动拒绝建窗（反调试）；DWM 扩展帧边界取可见区域 |
| 11 | gh-pages 用独立分支 + css 副本 | Pages 免安装预览的最低成本形态；代价是副本须随版本同步（已入 SOP） |
| 12 | 公开/私有双远端、双分支模型 | 公开端去敏（LICENSE 仅 GitHub ID）；私有端全量；private-full 每次 merge 垫顶、永不 force |
